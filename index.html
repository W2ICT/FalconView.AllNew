MEF & elevation settings
The MSA in each doghouse = the highest MEF (Maximum Elevation Figure) of the graticule quadrangles within 5 NM of the leg, plus 1,000 ft (2,000 ft when that MEF is above 5,000 ft). Type the figures printed on your chart with Tools → Enter chart MEF. Quadrangles you have not entered are estimated from DTED and marked *.
Google key for elevation (optional)
Your own Google Maps Platform key with the Maps JavaScript API and Elevation API enabled. Kept only in this browser; Google bills the usage. Without it the app uses DTED.
